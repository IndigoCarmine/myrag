# Agent Instructions

## Environment

* Use the project root directory
* Python environment is created from `pyproject.toml`
* Virtual environment is generated automatically by `uv`
* All dependencies must be installed via `uv`

## Coding Standards

* Strict typing is mandatory

  * Use type hints for all functions, methods, variables, and return values
  * Prefer `typing` and `pydantic` where appropriate
* Follow structuring principles:

  * Clear module boundaries
  * Separate I/O, domain logic, and orchestration

## Linting and Formatting

* Apply the following tools:

  * `ruff` for linting
  * `black` for formatting
* Code must pass all linters before execution

## Logging

* Use structured logging
* Include:

  * timestamp
  * log level
  * message
* Log to file in addition to console

## Error Handling

* All exceptions must be caught and either processed or escalated
* Error messages must be explicit and actionable
* For recoverable failures, retry with backoff

## Testing

* Unit tests for all modules
* Use `pytest`
* Coverage target: ≥ 80%
* Test design and structure is unrestricted: any organization, fixtures, parametrization, or custom plugins are permitted

## File Structure

```
project_root
  ├─ pyproject.toml
  ├─ services
  │   ├─ gateway
  │   ├─ embedding
  │   ├─ ingestion
  │   └─ storage
  └─ venv/ (auto-generated by uv)
```

## Execution

* Always run within the project root
* Use the virtual environment generated by `uv`

## Dependencies

* Install only from `pyproject.toml`
* No external downloads except via `uv`

## Documentation

* Each public function must have a docstring
* Provide argument description, return type, and raised exceptions
